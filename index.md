## 🛠️ Troubleshooting Common Issues

**Problem: The game won't start or crashes immediately.**
- Make sure you have the original game properly installed
- Check that your graphics drivers are up to date
- Try running OpenXvT as administrator (right-click the executable and select "Run as administrator",
- Verify that your system meets the minimum requirements listed above

**Problem: I can't find my original game installation folder.**
- If you installed via Steam, check `C:\Program Files (x86)\Steam\steamapps\common\`
- If you installed via GOG, check `C:\GOG Games\` or your custom installation location
- Use Windows search to look for files named `XWingAlliance.exe` or `TIE95.exe` to help locate the folder

**Problem: The game runs but the graphics look wrong.**
- Make sure your graphics card drivers are current
- Try adjusting the graphics settings inside the launcher or game options menu
- Check that your system supports OpenGL 3.3 or later

**Problem: I get a message about missing DLL files.**
- Ensure you have the latest Microsoft Visual C++ Redistributable installed from Microsoft's official website
- Make sure your Windows is fully updated

**Problem: Sound is not working.**
- Check your system's audio settings make sure sound isn't muted in-game
- Verify your audio drivers are installed properly
- Try lowering the audio quality settings if you experience crackling or lag
